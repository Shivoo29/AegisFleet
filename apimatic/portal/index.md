# AegisFleet API (/docs/)

AegisFleet runs four AI agents for a PayPal seller. Agents never call PayPal directly: every action passes a guardrail gateway (kill switch, allowlist, money caps, human approval) and is sealed into a hash-chained Proof Ledger anyone can verify.

This portal, the SDKs and the context plugins are generated by APIMatic from the same OpenAPI spec the live server publishes at [`/openapi.json`](https://aegisfleet.solvor.co.in/openapi.json).

## Quick start [#quick-start]

Every console endpoint takes HTTP Basic auth (`judge` and the judge password from the Devpost page).

1. **Reset the demo:** `POST /api/demo/reset` puts Riya's jewellery shop back to its starting story.
2. **Send a scam email:** `POST /api/demo/scam_email`, then `GET /api/runs` to read Sentinel's verdict.
3. **Check the chain:** `GET /api/ledger/verify` returns `ok: true`. Call `POST /api/demo/tamper`, verify again, and it names the edited entry.
4. **Approve a held action:** `GET /api/approvals`, then `POST /api/approvals/{id}/approve`.
