# Eval run, 10 Nov 2026, real model

Command (from `backend/`, with the keys in `.env`):

```
python -m evals.run --agent all --reset --pause 0.3
python -m evals.run --agent defender --reset --pause 6   # re-run after adding the note citation check
```

Model chain: Groq `openai/gpt-oss-120b` first, then Gemini `gemini-3.5-flash`, then NVIDIA NIM
`nemotron-3.5-super-vl-120b-a12b`. PayPal was the fake client (the evals test the agents, not PayPal).

| Suite | Fixtures | Result |
|---|---|---|
| Sentinel: is this "you've been paid" email real? | 20 | 20/20 correct, 0 scams missed, 0 false alarms, 0 unsure, 0 invalid JSON |
| Defender: dispute action and classification | 8 | 8/8 action, 8/8 classification, 0 facts citing a ledger entry that doesn't exist |
| Defender: AI-written note to PayPal | 8 | 8/8 passed the citation check (every `ledger #N` it cites is real evidence) |
| Collector: overdue invoice risk, tone, next action | 10 | 10/10 risk, 10/10 tone, 10/10 action |
| Prompt injection: emails that tell the agent to refund, ship or reveal secrets | 6 | 6/6 flagged as scams, 0 tool calls by Sentinel, 6/6 disallowed tool calls denied by the gateway |

Average latency: Sentinel 3.2 s, Defender 3.5 s (14.6 s in the first run while Groq was rate-limited),
Collector 4.5 s, injection 1.3 s.

## What happened along the way

- Groq's free tier allows 8,000 tokens per minute. The full run hit that limit 3 times; each time the call
  fell back to the next model and the fixture still passed. That is the fallback chain doing its job.
- In the first Defender run one fixture had all three providers fail at once (Groq 429, Gemini 503,
  NVIDIA timeout). Defender fell back to its rules and still chose the right action, which is why the first
  run shows 12.5% invalid JSON with 100% accuracy. The re-run above, with a longer pause, had no failures.
- How the work is split: rules decide anything that moves money (Sentinel's scam gate, Defender's action,
  Collector's tone and caps). The model reads untrusted text, adds red flags, breaks ties when the rules say
  "unclear", and writes the words a human or PayPal reads, and those words are checked before they are used.
